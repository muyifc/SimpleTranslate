# 阅读笔记 MVP

## 目标

让用户在网页阅读、划词解读和文章导读过程中，将有价值的信息直接保存在扩展中，减少复制到其他笔记工具的操作。

本文档是阅读笔记第一版的需求源。实现与测试应以本文档为准。

## 用户场景

1. 用户选中文本并点击“释”，获得结合页面语境的解释后，可以一键保存原文与解释。
2. 用户生成文章导读后，可以一键保存当前导读。
3. 用户可以从悬浮菜单打开“阅读笔记”，查看本地保存的笔记。
4. 用户可以编辑笔记内容、删除笔记，或重新打开笔记对应的原网页。

## 功能范围

### 保存划词解读

- 解读成功后，在快速结果浮层中显示“保存笔记”。
- 保存内容包括：页面标题、页面 URL、选中的原文、解读结果、创建时间和更新时间。
- 保存成功后按钮显示“已保存”，避免当前结果重复点击。

### 保存文章导读

- 文章导读生成成功后，在右侧导读抽屉中显示“保存导读”。
- 保存内容包括：页面标题、页面 URL、导读内容、创建时间和更新时间。
- 不保存发送给模型的完整文章正文，避免本地存储重复占用。

### 阅读笔记抽屉

- 悬浮菜单增加“阅读笔记”。
- 复用现有右侧抽屉，不新增独立页面。
- 笔记按更新时间倒序排列。
- 每项显示页面标题、类型、内容摘要和更新时间。
- 点击笔记进入详情，可编辑正文并保存。
- 详情提供“打开原文”和“删除笔记”。
- 空列表显示明确的空状态。

## 数据模型

笔记保存在 `chrome.storage.local` 的 `readingNotesV1` 数组中：

```json
{
  "id": "note-uuid",
  "type": "interpretation | article-guide",
  "title": "页面标题",
  "url": "https://example.com/article",
  "sourceText": "划词原文，文章导读笔记为空字符串",
  "content": "解读或导读内容",
  "createdAt": 0,
  "updatedAt": 0
}
```

约束：

- 最多保留 300 条笔记；超过后删除更新时间最早的笔记。
- 标题最多 300 个字符，URL 最多 2,000 个字符。
- 划词原文最多 1,200 个字符，笔记正文最多 10,000 个字符。
- 只接受 `http:` 和 `https:` 原文链接。
- 存储读取失败时显示错误，不覆盖已有笔记。

## 交互布局

划词解读：

```text
┌──────────────────────────────┐
│ 语境含义 / 通俗解释 / 名词    │
│                    [保存笔记] │
└──────────────────────────────┘
```

文章导读：

```text
┌────────────文章导读────────────┐
│ [保存导读]                 [×] │
├───────────────────────────────┤
│ 摘要 / 脉络 / 核心观点 / 名词   │
└───────────────────────────────┘
```

笔记列表与详情复用同一右侧抽屉：

```text
┌────────────阅读笔记────────────┐
│ 笔记列表                        │
│ ┌ 标题 / 类型 / 摘要 / 时间 ┐   │
│ └──────────────────────────┘   │
│                                │
│ 详情：正文编辑 / 保存 / 打开 / 删除│
└───────────────────────────────┘
```

## 安全与隐私

- 笔记只保存在本机扩展存储，不发送给新的第三方服务。
- 模型请求行为保持不变；保存操作不会再次调用模型。
- 页面标题、URL 和模型返回内容均按纯文本渲染，禁止赋值给 `innerHTML`。
- 笔记列表和详情渲染在关闭的 Shadow DOM 中，避免网页脚本读取其他页面保存的笔记。
- “打开原文”前重新校验 URL 协议。
- 笔记不并入包含 API Key 的设置导入/导出文件。

## 验收标准

- 划词解读和文章导读可以分别保存为不同类型的笔记。
- 保存后重新加载页面或重启扩展，笔记仍然存在。
- 阅读笔记抽屉可以查看、编辑、删除和打开原文。
- 删除或编辑一条笔记不会影响其他笔记。
- 第 301 条笔记写入后只保留更新时间最新的 300 条。
- 现有整页翻译、划词翻译、划词解读和文章导读测试继续通过。

## 非目标

- 标签、文件夹、全文搜索和知识图谱。
- Notion、Obsidian 等第三方笔记集成。
- 云同步、账户体系和跨设备同步。
- Markdown/JSON 导出与批量导入。
- 自动保存、网页高亮和批注定位。
- 相关文章搜索。
