# 独立阅读笔记页 V1

## 目标

将完整笔记列表和详情编辑从网页侧边抽屉迁移到扩展内部页面，给最多 300 条本地笔记提供稳定的浏览与编辑空间。

本文档是独立阅读笔记页第一版的任务与验收来源。

## 用户场景

1. 用户在网页中保存划词解读或文章导读后，可以从悬浮菜单打开完整笔记页。
2. 用户可以在笔记页左侧浏览按更新时间倒序排列的笔记。
3. 用户点击笔记后，可以在右侧查看原文、编辑正文、保存修改、打开原网页或删除笔记。
4. 用户删除笔记后，列表与详情立即同步。

## 本版范围

- 新增扩展内部页面 `notes.html`，不依赖联网服务。
- 新增 `notes.js` 和 `notes.css`，直接读取现有 `chrome.storage.local.readingNotesV1`。
- 桌面端使用“列表 + 详情”双栏布局，窄屏改为上下排列。
- 列表显示标题、类型、摘要和更新时间，并按更新时间倒序排列。
- 默认选中第一条笔记；空列表显示空状态。
- 详情支持编辑正文、连续保存、删除和打开经过协议校验的原文链接。
- 悬浮菜单“阅读笔记”改为通过后台打开独立扩展页。
- 网页侧边抽屉继续承载文章导读，但不再承载完整笔记列表与详情。
- README 增加独立笔记页说明。

## 布局

```text
┌────────────────────── 阅读笔记 ──────────────────────┐
│ 本机保存的解读与导读                                  │
├───────────────────────┬──────────────────────────────┤
│ 笔记列表              │ 笔记详情                     │
│ 标题 / 类型 / 摘要 / 时间│ 原文 / 正文编辑 / 操作       │
│                       │                              │
└───────────────────────┴──────────────────────────────┘
```

窄屏时列表与详情上下排列。

## 数据与安全

- 沿用 [阅读笔记 MVP](reading_notes_mvp.md) 的数据模型、字段长度和 300 条上限。
- 页面标题、原文和笔记正文只使用纯文本渲染。
- 只允许打开 `http:` 和 `https:` 原文链接，点击时再次校验协议。
- 删除前必须确认。
- 存储读取或写入失败时显示错误，不覆盖已有笔记。
- 笔记仍不并入设置导入导出文件。

## 验收标准

- `notes.html` 可以加载现有两种类型的笔记，并按更新时间倒序显示。
- 默认详情与当前选中列表项一致。
- 修改正文后可连续保存，刷新页面后仍能读到最新内容。
- 删除当前笔记后，列表数量减少并选择下一条；删除最后一条后显示空状态。
- 不合法的原文 URL 不显示“打开原文”。
- 悬浮菜单不再打开侧边笔记列表，而是请求后台打开 `notes.html`。
- 现有保存解读、保存导读、文章导读、翻译和设置测试继续通过。

## 非目标

- 搜索、标签、文件夹、排序选项和批量操作。
- Markdown/JSON 导出与导入。
- 云同步、账户体系和第三方笔记集成。
- 在侧边栏展示最近笔记；需要验证独立页使用频率后再决定。
