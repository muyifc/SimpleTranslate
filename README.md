# 双语网页翻译

一个无需构建的 Chrome / Edge Manifest V3 扩展。网页边缘可拖动的悬浮球会按需启动翻译：它识别当前可见正文中的非母语内容，通过用户配置的 OpenAI-compatible Chat Completions 接口逐段翻译，并把母语译文插入原文下方。

## 安装

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，并选择本仓库目录。
4. 从扩展弹窗打开“设置”，添加并激活一个或多个模型配置；每项包含 Chat Completions API 地址、模型和可选 API Key，首次保存时允许扩展访问对应 API 域名。
5. 打开或刷新普通网页，通过扩展弹窗的“当前网页翻译”开关或页面右侧的“译”悬浮球开始翻译。

右键悬浮球可以生成当前正文区域的文章导读、隐藏悬浮球、选择并保存正文区域、清除区域规则、禁用网站、重试失败段落，以及切换原文/译文；隐藏后可从扩展弹窗重新显示。选中文字后点击旁边的“译”可快速翻译，点击“释”可结合页面语境获得通俗解释和关键名词说明；按住 `Alt` 悬停英文段落约 0.4 秒可查看译文。

配置保存在 `chrome.storage.local`。API Key 不会写入源码，但浏览器扩展本身不能真正隐藏个人密钥；公开发布前应改用服务端短期令牌。

## 当前范围

- 正文区域优先选择 `main` 内的 `article`，其次是 `main` / `[role="main"]`，再回退到独立 `article` 或 `body`。
- 段落候选：标题、段落、文本型 `div`、列表项、引用和表格单元格。
- 排除导航、页眉页脚、侧栏、广告、弹窗、代码、表单、可编辑区域和 `translate="no"` 内容。
- 使用 Chrome/Edge 原生语言检测，把识别出的非母语段落发送给翻译服务；母语在设置页选择。
- 保留正文中的显式换行，并让译文继续保持编号列表、项目符号和段落结构。
- 可视段落以最多 3 段的微批请求发送，同时最多处理 3 个请求；批量失败时自动降级为单段重试。
- 限流（429）、服务端错误（5xx）和网络故障会自动指数退避重试最多两次；取消翻译会立即中止等待中的重试。
- 只发送进入当前可视区域的段落；滚动后继续翻译新进入视口的内容。
- 段落需在视口内短暂停留才会入队；快速滚动经过的内容会撤销，已完全离屏的请求会取消，让当前视口优先使用并发槽。
- 页面左右边缘显示可上下拖动、可换边的悬浮球；翻译时以 `已完成/总数` 和水位动画显示当前可视任务进度，完成后显示 `✓`，再次点击会停止翻译。
- 右键悬浮球可直接取消翻译、恢复原文或显示译文。
- 可以按网站保存用户选择的正文区域；规则失效时自动回退到通用正文识别。
- 支持按网站禁用、清除区域规则和重试失败段落。
- 译文按模型配置、接口、语言、术语表和页面语境持久缓存；缓存键经哈希压缩，并可在设置页中清空。
- 设置页可配置模型和逐行 `原词=译词` 的术语表；弹窗只保留当前页面的翻译、译文和悬浮球开关。
- 设置页可用 JSON 导入或导出母语、术语表、站点规则和全部模型配置；文件包含 API Key，页面会提示不要上传或转发。
- 整页翻译的每段额外携带前后邻段原文作为只读语境，模型可消解代词、歧义词和跨段术语；邻段不作为待翻译内容，且会参与缓存隔离。
- 最多配置并激活 4 个模型；同一段会并行生成各模型译文并标注名称，单个模型失败不会吞掉其他模型的结果。
- 支持选中文字后点击“译”翻译或点击“释”解读；解读仅使用第一个启用模型，并与翻译缓存隔离。
- 右键悬浮球可生成文章摘要、文章脉络、核心观点和关键名词，并在右侧抽屉中展示；首版最多读取 20,000 个字符。
- “取消翻译”会清空等待队列并中止当前页面正在进行的请求。
- 支持动态新增内容、隐藏译文和再次显示译文。

详细范围见 [实施方案](docs/bilingual_web_translation_extension_plan.md)。
